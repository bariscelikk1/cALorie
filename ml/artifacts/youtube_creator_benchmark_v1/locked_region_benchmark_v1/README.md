# cALorie locked creator region benchmark v1

This report compares frozen V6-C and V6-F on 36 locked regions from six reserved creator videos. All 14 supported labels plus unknown are present. No training, calibration, threshold selection, or relabeling occurred. The scope is region classification, not continuous long-video segmentation. See metrics.json, locked_region_benchmark_v1.csv, and region_predictions.csv.
