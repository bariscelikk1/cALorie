# RepCount visual adjudication v1

This directory archives the unchanged Notebook 38 return package. Its outer
SHA-256 is recorded in `SHA256SUMS.txt`; all 72 files listed by the package's
internal checksum manifest also pass verification.

The package contains evidence only: eight silent 240p review previews and 61
dense 4 FPS JPEG pages. It contains no raw source videos, training run,
checkpoint, threshold selection, or locked-benchmark access. Final decisions
derived from this evidence live in
`ml/data/repcount_development_v1/final_visible_adjudication_v1.csv`.
