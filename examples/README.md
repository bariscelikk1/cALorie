# Example videos

Expected filenames are listed in `evaluation/manifest.csv`. Videos are not
included because no consented, repository-owned recordings were supplied.

For the classroom demo, record three 20–40 second clips specifically for this
project. Obtain permission, avoid faces where practical, keep each file below
10 MB, and document the source in the manifest. Use Git LFS or the private
Supabase bucket if the combined assets become large.
