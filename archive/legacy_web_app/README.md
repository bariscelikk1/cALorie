# Legacy web app (archived 2026-10-28)

Code from the earlier version of cALorie: a Next.js website (`web/`), a Python
analysis worker (`worker/`, including early rep-counting and MET calorie
code), a Supabase schema (`supabase/`), a Render deployment file, a small
evaluation harness, and early design documents (`docs/`, including the Turkish
technical report). None of it is maintained, and it does not use the final
model. Kept unchanged for reference; the active project is under `ml/`.
